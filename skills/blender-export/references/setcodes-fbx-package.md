# Scoped FBX and texture delivery

Choose FBX only when requested or required by the consuming pipeline; a source author's personal FBX preference is not this project's choice. Distinguish static, existing skinned and newly rigged outputs. Save an owned export duplicate and resolve an explicit object manifest including intended armature/attachments; deselect every scene/view layer that the exporter might include and inspect the final parsed/reimported object set. Selection is not sufficient evidence that hidden source objects were excluded.

Record units and forward/up axes. `-Z` forward / `Y` up with metre-scale inputs is a candidate, not universal. Inspect actual exporter properties, choose deform/leaf-bone, sampling and animation options from the brief, and require FINISHED plus a newly created file. Do not reset matrices on the master or apply bound transforms blindly. For animation preserve rest/bind matrices, hierarchy and root-motion policy on a prepared copy; test conversions by actual imported world landmarks and poses.

Copy requested maps into a portable `textures/` directory with unique relative names. Albedo stays sRGB; normal/scalars stay Non-Color. If ORM must split, extract R to AO, G to roughness and B to metallic exactly, preserving dimensions/precision; no color conversion, grayscale weighting or invented remapping. Record normal Y orientation and any Unity/target smoothness conversion separately. Verify equality of each lossless extracted channel. AO may need manual target hookup; FBX embedding is not a universal PBR shader translation. Keep maps useful even if importer materials need rebuilding.

Move a copy of the package outside the source texture directory and reimport in an empty background process. Inspect every expected mesh, including props with 20 or fewer polygons. Compare evaluated counts, finite world coordinates, dimensions, ground, pivot and a known facing marker; a head's minimum y does not prove facing. Compare UVs/material assignments/role paths; check rig hierarchy, nonzero weights and requested clips/interior poses. A largest-mesh summary skips attachments and cannot establish the contract. Missing Head landmarks should mark a face render unavailable, not crash an otherwise useful inspection.

Preserve the source working file and old deliveries. Deliver the requested FBX, texture legend, hashes, exporter/importer versions/options, comparison values and current images. GLB byte-preserving texture mutation is a different operation: it cannot establish FBX geometry/skin invariants. Re-render and reimport the corrected revision after any failed check; do not merely edit a report to say it passed.
