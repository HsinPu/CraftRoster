# Reconstruct a thin generated vehicle shell

Select this branch after inspecting six source views and classifying open panels versus solid organic surfaces. Voxel remesh can destroy thin doors/roofs. Preserve source, glass/interior and separate moving parts. Record vehicle length, wheelbase, wheel centers, tire radius, camera domain and transparent/cutaway needs before deleting any interior. A top-down visibility test is invalid for a driving cockpit or underside inspection.

On a working duplicate isolate tire regions using measured axle cylinders; confirm fused tires versus separate components. Make a moderately reduced visibility target (around 100–150k triangles is an initial workload choice). For each face sample several interior points, offset by a scale-derived epsilon, and cast outward directions spanning the required viewing hemisphere/horizon. Consider only directions facing the surface. Keep a face if any required-view ray escapes; keep uncertain faces and those needed by shadows, glass or motion. A fixed 50-direction test is sampled evidence, not a proof of global invisibility. Preserve uncensored geometry for rebakes.

Build a longitudinal cage from a stable set of ray families. Start perhaps 36 stations across a compact car, adding stations around rapid curvature. At each station use the same horizontal rays at specified heights and vertical rays at specified widths, so index i has the same geometric meaning throughout. Mirror only the symmetric stage. Do not independently resample perimeter arc length at each station: correspondence rotates and the loft twists. For a missing hit, mark it, use a bounded neighbor interpolation or previous valid point only provisionally, and inspect the resulting section; long missing spans require another measurement rather than a hidden clamp. Exclude mirrors only when both beyond measured body width and above belt line; ordinary fenders must remain.

Connect corresponding section vertices, close the required end/floor regions at actual sill height, then use simple subdivision for sampling. Shrinkwrap nearest-surface to the owned visible target with a bounded distance; inspect wrong-side jumps at thin panels. Smooth moderately and shrinkwrap again. Pin measured sill/panel planes where appropriate. Reduce the resulting body to its explicit budget while retaining wheel openings, hood/roof silhouette and light regions. Check per-section dimensions and degenerates, since whole-object bounds can hide collapsed parts.

Rebuild tires as measured cylinders with enough sides at gameplay distance (14–16 is a low-distance starting candidate), correct outer/inner visible caps and actual wheel pivots. Keep wheels separate when they steer/spin. Add genuinely missing lamps/mirrors/bumpers from reference, marking inference. Before selected-to-active bake split intended sharp normals consistently with UVs and final triangulation; averaged cage rays at a hub can hit the tire instead. Scale cage/ray distance from actual panel gaps. Bake albedo through emission so chrome does not become black through a diffuse metallic response.

For a missing part, use an owned temporary face subset with the same atlas UVs and bake a procedural/paint candidate only into its mask. Preserve existing albedo outside that mask; use no-clear only after validating active targets and overlap. Sample nearby same-material color rather than a global median. Flatten floor normals only if every required view excludes it. Compare tire hubs, roof highlights, fenders, rear lamps and low-angle body silhouette, then test wheel motion and the actual exported shader. Worn variants remain optional and share the confirmed atlas correspondence.
