# Narrative and Visual Novel Sets

Record story beat, viewpoint, blocking and output: VN plate, interactive film or walking scene. Collect approved dialogue masks and composition. Emotional framing is an art goal, not proof of audience response.

Read the shared [asset contract](../blender-development/references/asset-contract.md), [execution and ownership](../blender-development/references/execution-and-ownership.md), [quality loop](../blender-development/references/quality-loop.md) and [world/genre production contract](../blender-development/references/world-and-genre-production.md). These are foundation resources, not an instruction to run another complete workflow.

For production, read [the subject playbook](references/production-playbook.md) for the kit, construction, concrete recipe, variants, diagnostics and repairs. Example dimensions are configurable proposals; preserve settled project rules, existing scene and approved visual references.

For a selected subtype, read [the detailed variant workflows](references/variant-workflows.md); each branch supplies construction, look, diagnosis/repair and specific acceptance.

Begin with scale and intended camera, inspect the blockout before dressing, then correct image-supported defects. An authorized writer may build, render, repair and save. Read-only review returns findings without modifying scenes or persisting reports. The [evaluation definitions](evals/evals.json) are realistic assessment inputs, not executed evidence.

Conditional companions: `blender-camera-cinematography`, `blender-lighting`, `blender-compositing`. Use the relevant installed companion only for requested work; these names do not automatically install or activate it. `blender-export` applies to requested delivery formats; `blender-asset-validation` supports technical checks.

Deliver editable assets, requested variants, assembly/scale notes and current-revision review images. Report technical checks, actual visual inspection and target-engine results separately. Missing image inspection leaves visual acceptance unverified; renders cannot establish gameplay, AI, balance or engine performance.
