# Reconstruct elevations and bake a projected atlas

Inspect the entire supplied sheet and record pixel rectangles for each elevation, its projection, subject landmarks and rights. Preserve the original; crop/grid only copies. Pick a measured anchor to convert pixels to metres, or label the chosen door/person size an estimate. Conflicting AI views need an explicit authoritative view/use-case choice. A majority of drawings is not a physical measurement. Organic modeling can also use manual sculpting or other authorized workflows; a generator is not mandatory.

For each part/view store a table of world extents, pixel extents, facing axis and mirrored direction. A linear coordinate mapping is `p=p0+(s-s0)*(p1-p0)/(s1-s0)`; reject zero spans and inconsistent landmarks. Calibrate each part separately when the artwork contradicts a global projection, documenting the compromise. Convert image top-left pixels to bottom-left UV with `u=pixel_x/W`, `v=1-pixel_y/H`. Verify handedness with an asymmetric marker: a camera at +X sees different front/back screen directions than -X. Do not blindly mirror a back elevation twice.

Block main volumes and openings, compare fixed-world orthographic silhouettes first. Assign each face a view using its world normal and actual visibility. Dominant-axis mapping is a starting point; roofs, thin skirts, side-mounted chimneys and steps often require explicit part overrides. An unseen underside gets a declared neutral material or separate authored view, not invented visible detail. Map only the confirmed part rectangles; wide rectangles on a narrow elevation pull in background stripes.

Before sampling, grow foreground colors into a separate reference copy with a bounded same-edge neighborhood. Detect background from declared RGB/mask with tolerance rather than assuming a corner is empty. Use padded neighborhoods; `np.roll` joins opposite image edges and can contaminate the crop. Preserve intentional internal holes/masks. Record growth radius and inspect outline halos. Bleed cannot resolve occluded faces or recover texture detail absent from the sheet.

Create a dedicated projection UV layer and an explicit UV Map node reading it; keep the atlas UV distinct. Render front/back/sides/top before baking and inspect every overridden part. Generate a new atlas UV, set its active and active-render/bake roles deliberately, and assign fresh target images for every low material. Reusing an image datablock whose backing file was removed can produce uninitialized-image failures. Bake the defined color signal via emission rather than assuming a diffuse color pass handles arbitrary metal/shader graphs. Restore original output links/active nodes in `finally`.

Bake separate AO if requested; pack ORM only with documented defaults and retained scalar sources. An albedo-luminance normal is an optional artistic emboss proxy that can turn painted shadows into false bumps. If used, compute on a rectangular W-by-H buffer, apply bounded blur/derivatives with no wrapped edges, normalize vectors and inspect both light directions. Do not replace a real normal bake or apply this to character cleanup by default. Remove projection-only layers/materials only from the delivery duplicate after saved-source and output checks.

For an external texturer handoff, an alternative is geometry-only construction: recesses with actual depth, U-shaped casings, sills, cornices, braces, separate flue interior and meaningful material zones. Spend triangles on features the texturer must identify. Keep UV/no-UV state explicit. Remove confirmed glued contact faces and same-facing coplanar overlaps using robust planar intersection; sampled barycentric coverage is only a diagnostic. Cut roof underside to visible soffits rather than wasting a large atlas region inside a closed attic. Recess/trim neighboring colors, duplicated painted handles and baked chimney shadows are inspection targets, not guaranteed behavior of an external service. Do not contact that service without task authority.

Deliver pixel/world/part-view tables, camera settings, projection source, atlas version, source/target dimensions, texel-density limits and comparisons at gameplay and close range. Reference lighting remains baked unless actually corrected. A small multi-view sheet can be visibly soft; upscaling does not restore its missing source detail. A hybrid tiled surface plus projected unique details can improve density without pretending the sheet supplied unseen information.
