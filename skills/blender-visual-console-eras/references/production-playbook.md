# Console and Media Era Look Studies: production playbook

## Brief, scale and evidence

Choose concrete reference cues rather than one universal console-generation style. Asset resolution, CRT display, VHS recording and film are different stages. Use rights-cleared assets and do not claim hardware-accurate emulation from a styled render.

## Asset kit and construction

Geometry/UV/material variants, palette/filter chart, fixed camera, clean render and isolated compositor treatments. Preserve original textures and unprocessed output.

Choose density/filtering/light from reference. Keep affine-like distortion, snapping, dithering and quantization independently controllable. Do not corrupt topology to imitate cracks. Modern inspiration still needs coherent budgets/materials, not automatic scan density.

## Bounded layout recipe

These dimensions are a starting study, not established game rules.

1. Build a room/prop baseline at intended size and write selected era cues as a short contract.
2. Early 3D: simplify silhouettes and make low-resolution texture variants; compare filtering and any instability independently.
3. Later eras: add selected material/light detail using equivalent camera comparisons and record which cues belong to assets/rendering.
4. Add only requested CRT/VHS/film/DOS/arcade treatment; export clean/treated pairs and parameter sheet, plus temporal samples where needed.

## Diagnostic images and acceptance

Clean/treated pair, UV/filtering close-up, grayscale silhouettes and palette/edge chart. Inspect several frames for grain/scanline/tracking/motion behavior; a still cannot validate temporal stability.

## Specific failures and repairs

Scanlines erase details: reduce treatment or strengthen source forms. VHS blur mistaken for source texture: restore separate clean baseline. Wobble creates holes: use reversible presentation approximations without corrupting delivery mesh.
