# Blender specialist index

Choose the task-specific entry below. Names are conditional routes, not an instruction to install or load every package. The foundation can handle a bounded small task directly. Specialist resources load only when needed; style and world/genre entries combine with the relevant production discipline.

## Install and handoff boundaries

The foundation has no required companion. Ordinary specialists require its shared resources only. Common export also requires asset validation; engine-specific exporters additionally require common export. A conditional route is available guidance, not a hard dependency. Before handing off, confirm the named Skill is installed and the current agent has the necessary permissions. The visual reviewer remains read-only.
