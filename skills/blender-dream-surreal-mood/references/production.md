# One impossible rule

## Choose dream logic

State one rule: gravity points toward a door, a room contains a larger copy, or a floating object casts an ordinary shadow. Choose emotion separately: wonder and grief need not receive horror treatment. Keep a mundane anchor that makes the violation understandable.

## Build a study

For a floating-table scene first build a plausible room and doorway scale cue. Suspend the table and make cloth hang toward a sideways gravity direction. Retain a normal chair to establish inconsistency. For recursion, align nested room copies to the hero camera; identify the result as camera construction rather than a traversable impossible building. Avoid combining every device by default.

Use distinguishable simple finishes so the violation dominates. A large soft source suggests reverie; a crisp colored pool may heighten strangeness. Test shadow direction deliberately: an ordinary shadow can make floating geometry convincing. Compare a normal/short-telephoto lens before extreme wide angle, which can disguise scale play as distortion. Keep mist and halation adjustable and retain a clean image.

## Diagnose and judge

Random-prop readings need fewer motifs and a clearer anchor. Apparent technical errors need consistent violation across related objects. If everything looks soft, recover an edge hierarchy with a crisp focal object and gentler supporting forms.

Inspect intended and atmosphere-off images plus a diagram or alternate view explaining the construction. Accept when contradiction, emotion and focus are readable. A moving camera requires an actual path test; a forced-perspective still does not establish a coherent illusion from every angle.
