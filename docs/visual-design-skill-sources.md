## Rewrite Rules

- Preserve `source: HsinPu/CraftRoster` and `author: HsinPu` in canonical catalog metadata.
- Keep primary external provenance in supported `reference-source` metadata; use this ledger for additional research inputs rather than pretending they are first-party discoveries.
- Reframe every adopted mechanism around CraftRoster routing, approval, ownership, privacy, accessibility, and verification contracts.
- Do not import executable hooks, remote instruction fetching, datasets, model weights, provider configuration, or prompt text without a separate security, license, and maintenance review.
- Treat an unclear or absent license as concept-only research: no code or text reuse.
